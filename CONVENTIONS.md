# Project Conventions

Project: Personal About Me website.
Technology: HTML and CSS.
Current file: docs/index.html.
Purpose: A simple and responsive student website.

## Rules

1. Use HTML and CSS only.
2. Use kebab-case for CSS class names.
3. Use two-space indentation.
4. Use UK English spelling.
5. Keep colours in CSS variables.
6. Keep the existing sections unless changes are requested.
7. Use simple and readable code.
8. Check the layout on mobile screens.
